# ⛏️ Dig Deeper

Dig Deeper is a `Python` mining game developed by Meakz.

Start with a `basic drill` and work your way towards building a mining empire. `Discover valuable materials`, `sell your loot`, and `upgrade your equipment` to `dig deeper` and `earn more`.

## 🛠️ Built With
- `Python`
- `Pygame`
